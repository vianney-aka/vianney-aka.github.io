**Technologies** : JavaScript ES6+, Vanilla JS

## 🎯 Parcours Recommandés

### 🚀 Parcours Express (30 minutes)

1. **[QUICKSTART.md](QUICKSTART.md)** (5 min)
   - Lire les 3 étapes principales

2. **Préparer les images** (10 min)
   - Voir **[assets/README.md](assets/README.md)**
   - Ajouter les 5 images essentielles

3. **Personnaliser** (5 min)
   - Modifier nom, email, téléphone dans `index.html`
   - Mettre à jour liens sociaux

4. **Déployer** (10 min)
   - Suivre **[QUICKSTART.md](QUICKSTART.md)** section déploiement
   - Commandes Git de base

---

### 📚 Parcours Complet (2-3 heures)

1. **Comprendre** (30 min)
   - **[README.md](README.md)** - Vue d'ensemble
   - **[PROJECT_SUMMARY.md](PROJECT_SUMMARY.md)** - Détails
   - Explorer `index.html`, `styles.css`, `script.js`

2. **Préparer** (45 min)
   - **[IMAGES_GUIDE.md](IMAGES_GUIDE.md)** - Créer toutes les images
   - Optimiser avec TinyPNG
   - Ajouter dans `assets/`

3. **Personnaliser** (45 min)
   - **[CUSTOMIZATION.md](CUSTOMIZATION.md)** - Tout personnaliser
   - Modifier couleurs, projets, compétences
   - Configurer Formspree

4. **Déployer** (20 min)
   - **[DEPLOYMENT.md](DEPLOYMENT.md)** - Déploiement complet
   - **[GIT_COMMANDS.md](GIT_COMMANDS.md)** - Commandes Git

5. **Tester** (30 min)
   - **[TESTING_CHECKLIST.md](TESTING_CHECKLIST.md)** - Tous les tests
   - Lighthouse audit
   - Tests responsive

---

### 🔧 Parcours Maintenance

1. **Mettre à jour le contenu**
   - **[CUSTOMIZATION.md](CUSTOMIZATION.md)** - Section concernée
   - Modifier `index.html`

2. **Pousser les changements**
   - **[GIT_COMMANDS.md](GIT_COMMANDS.md)** - Workflow quotidien
   ```bash
   git add .
   git commit -m "Update: description"
   git push origin main
   ```

3. **Vérifier**
   - **[TESTING_CHECKLIST.md](TESTING_CHECKLIST.md)** - Tests rapides
   - Attendre 2-3 minutes
   - Vérifier le site en ligne
